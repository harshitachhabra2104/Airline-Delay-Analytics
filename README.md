# Airline Delay Analytics

End-to-End Data Analytics Project using Python, SQL and Power BI.

## Project Overview

This project analyzes over 1.9 million airline records to uncover operational trends, flight delay patterns, airline performance, airport traffic, and weather impacts.

---

## Tech Stack

- Python
- Pandas
- DuckDB SQL
- Power BI

## Key Business Insights

- Southwest Airlines operated the highest number of flights.
- Morning flights generally had fewer delays.
- Weather conditions influenced flight delays.
- Certain airports consistently experienced higher delay rates.
